# Damascus Wedding Invitation — FINAL

نسخة نهائية جاهزة للرفع مباشرة إلى GitHub Pages.

## الشيء الوحيد الذي تعدّله لكل عرس
افتح `config.js`.
كل بيانات العروسين والنصوص والتاريخ والمكان والبرنامج والألوان موجودة فيه.

## الصور
الصور الثلاث مرفقة فعلياً داخل `assets/`:
- `hero.jpg`
- `venue.jpg`
- `dinner.jpg`

يمكن إبقاؤها أو استبدال أي صورة بنفس الاسم.

## الموسيقى
`assets/music.wav` موسيقى Ambient أصلية بسيطة مرفقة حتى يعمل الموقع فوراً.
إذا كان لديك ملف مرخّص للموسيقى التي يريدها العميل:
1. ضعه داخل `assets/`
2. غيّر قيمة `music` في `config.js`.

ملاحظة: رابط YouTube لا يتم تنزيل الصوت منه أو إعادة توزيعه داخل المشروع.

## GitHub Pages
ارفع **محتويات هذا المجلد** إلى Root للـ repository:
index.html / style.css / script.js / config.js / assets
ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).
